# Montevideo Landings

Este repositorio aloja páginas de muestra generadas automáticamente para
negocios de Montevideo que todavía no tienen sitio web propio.

## ¿Qué es esto?

Cada carpeta bajo `docs/` es una página de muestra construida a partir de
datos públicos de un negocio real (nombre, dirección, horario, contacto),
generada para mostrarle a su dueño una posible versión de su propio sitio.
No es el sitio oficial del negocio, ni fue publicada por el negocio mismo —
lo aclara el pie de página de cada página.

## ¿Sos el dueño de uno de estos negocios?

Si llegaste acá y no pediste esta página, podés simplemente ignorarla: no se
indexa en buscadores (lleva `<meta name="robots" content="noindex, nofollow">`)
y se elimina automáticamente pasado un tiempo (ver `landing expire` en el
proyecto). Si querés que se elimine antes, o tenés alguna otra consulta,
escribinos a quien te la haya compartido.

## ¿Por qué es pública?

GitHub Pages en un repositorio privado requiere un plan pago; en uno público
es gratis. Por eso cada página usa una URL con un sufijo aleatorio
imposible de adivinar, en vez de depender de que el repositorio sea privado
para no ser encontrada.
